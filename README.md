# Drag & Drop Digits

A small React + Vite application that lets you reorder the digits 0–9 with native HTML5 drag and drop. Dropping a digit into another slot inserts it at that position and shifts the digits in between rather than swapping two digits.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Project structure

```text
src/
  App.jsx       # Drag-and-drop state and behavior
  main.jsx      # React entry point and Bootstrap import
  styles.css    # Layout and drag/drop appearance
index.html
package.json
```
